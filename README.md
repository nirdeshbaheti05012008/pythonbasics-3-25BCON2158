# Student Object in Python 🐍

A simple Python program that creates a student object, assigns attributes to it, and displays the student's details.

## 📌 Project Description

This project demonstrates how to create a class and an object in Python and assign data to an object using attributes.

The program defines a `Student` class, creates an object named `s1`, and assigns the student's name, roll number, and marks. Finally, it prints these details in a readable format.

## 🔍 What Does This Program Demonstrate?

In Python, a **class** defines a type of object, while an **object** is an instance of that class. Attributes store information associated with an object.

In this example, the `Student` object stores:

- Name: Rahul
- Roll number: 101
- Marks: 87.5

## ✨ Features

- Simple and beginner-friendly Python implementation.
- Defines a class named `Student`.
- Creates an object using the class.
- Assigns attributes dynamically to the object.
- Displays student details using `print()`.
- Formats marks to one decimal place.

## 💻 Example

### Student Details

```python
s1.name = "Rahul"
s1.roll = 101
s1.marks = 87.5
```

### Output

```text
Name: Rahul
Roll: 101
Marks: 87.5
```
